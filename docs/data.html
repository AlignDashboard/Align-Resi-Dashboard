Every number on this dashboard starts as a file somebody else produced. This is the chain each one travels: the Google Drive folder it lands in, the export itself, the script that reads it and what that script checks before believing it, the scrubbed copy kept in data/, the JSON the site fetches, and the card it finally shows up on. Where a chain stops short it is drawn stopping short — a report can arrive, parse and tie out and still feed nothing.
Nothing in this repo puts files in Drive. A Gmail script reads dashboard@alignrealestate.com hourly and files each attachment into a folder by matching its name — so the first stage below names the words it matches on, which is what actually decides where a report goes. Anything it cannot place lands in _Unsorted and reaches nothing.
The numbers behind each chart on the dashboard, exactly as the page reads them — no rounding or abbreviation. Each table names the chart it feeds and the source it came down from, and can be downloaded as CSV. Larger tables have a filter box.
